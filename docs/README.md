# IMedora Documentation

Central location for all project documentation.

## Structure

- `architecture/` — system architecture decisions, diagrams, and rationale.
- `api/` — API contracts and endpoint documentation (once APIs are designed).
- `database/` — data model documentation, ER diagrams, and migration notes.
- `ai/` — AI service design, agent/RAG architecture, prompt and tool documentation.
- `requirements/` — functional and non-functional requirements gathered from stakeholders.

Each subfolder contains its own `README.md` describing its intended contents in more detail. Documents should be added incrementally as decisions are made — this repository does not yet contain finalized architecture, API, database, or AI designs.
